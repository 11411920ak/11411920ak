**Multi-Layer Anti-Proxy Attendance System**

A QR-based attendance platform designed to reduce proxy attendance using time-based QR validation, GPS verification, and duplicate-scan prevention.

* ☁️ Serverless deployment using Cloudflare Pages & D1
* ⚡ Sub-second QR verification
